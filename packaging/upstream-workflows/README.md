# Archived upstream workflows

These are the original Spotifast workflow files, preserved byte for byte as
`.yml.txt` reference files. They are outside `.github/workflows`, so GitHub
Actions does not run them in this repository.

Several refer to upstream publishing destinations, scheduled triage, shared
automation or repository secrets. Review and adapt each workflow before enabling
any Motion Music automation. Motion Music v7 is distributed manually through
[this repository's release](https://github.com/MaybeMotion/Motion-Music/releases/tag/motion-v7).
